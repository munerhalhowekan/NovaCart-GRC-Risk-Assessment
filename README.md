# NovaCart Cybersecurity Risk Assessment

A GRC portfolio project assessing cybersecurity risks for **NovaCart**, a fictional e-commerce company.

The project demonstrates a structured approach to identifying cybersecurity risks, evaluating security control gaps, developing risk treatment actions, and assessing residual risk.

## Scope

The assessment covers key organizational assets, including:

- Customer and payment data
- E-commerce website
- Corporate email
- Employee endpoints
- Cloud storage
- Internal network
- Privileged accounts

## Methodology

The risk assessment follows principles from **NIST SP 800-30 Rev. 1**, including:

1. Asset and threat identification
2. Vulnerability and predisposing condition identification
3. Likelihood assessment
4. Impact assessment
5. Risk determination
6. Risk treatment
7. Residual risk assessment

Relevant controls from **NCA NCNICC 1:2025** were used to assess security gaps and recommend appropriate controls for the simulated private-sector environment.

## Key Findings

The assessment identified **12 cybersecurity risk scenarios**. Key areas requiring improvement included:

- Identity and privileged access management
- Patch and vulnerability management
- Cloud access permissions
- Protection of sensitive customer and payment data
- Endpoint security and encryption
- Backup and recovery
- Security awareness and phishing protection

## Risk Treatment

Risk treatment actions were developed for each identified risk, including:

- Enforcing MFA and least privilege
- Improving patch management
- Strengthening cloud permissions
- Implementing endpoint protection and encryption
- Improving backup and recovery
- Conducting recurring security awareness training

Residual risk was reassessed after assuming successful implementation of the recommended controls.
